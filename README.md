# Linear Control Systems — Academic Coursework

I completed this core electrical-engineering course at Sharif University of Technology under Professor Behzad Ahi in Fall 1404 (2025–2026), earning 18.6/20. This repository documents my work as a student: six analytical homework submissions, MATLAB/Simulink exercises, and a quarter-car suspension control project.

My coursework covers dynamic modeling, response analysis and model reduction, stability criteria, root locus, frequency-response design, and time-delay systems. The later computational exercises include Nichols-based gain tuning, critical-gain analysis, and delayed-system pole calculations using Lambert W.

## Running the computational work

Most scripts require MATLAB and Control System Toolbox. Simulink models require Simulink. Identification exercises may require System Identification Toolbox; symbolic calculations and Lambert W require Symbolic Math Toolbox. Each homework includes browsable reports and MATLAB previews, together with lossless ZIP parts preserving the complete original submission. Extract all parts into the same directory to restore the original paths before loading data. Some original scripts use local or experiment-specific data assumptions and may require path or input adjustments.
